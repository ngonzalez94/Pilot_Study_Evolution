# =====================================================
# Align 5 predicted structures to a reference, separate
# them, colour by secondary structure, reference by pLDDT
# =====================================================
#
# HOW TO USE: only change the lines marked "EDIT".
#   EDIT 1: output folder
#   EDIT 2: reference model number and the 5 predicted model numbers
#   EDIT 3: spacing between models (Angstroms)
#
# =====================================================

# ---------- EDIT 1: output folder ----------
cd "C:\Users\natal\OneDrive\Documents\Thesis\Chapter 3"

# ---------- EDIT 2: model numbers ----------
name ref #2
name preds #1,3-6

# ---------- 1. Align all predicted structures onto the reference ----------
# matchmaker uses a sequence alignment, so the ~20 aa difference in length is handled.
# RMSD for each alignment is printed in the Log.
matchmaker preds to ref
log save alignment_rmsd_log.html

# ---------- 2. Separate the models without changing their orientation ----------
# EDIT 3: change 50 to the spacing you want. The reference stays in place.
# "coordinateSystem #2" moves along the reference's own x axis,
# so the spacing stays the same however you have rotated the view.
move x 50 models #1 coordinateSystem #2
move x 100 models #3 coordinateSystem #2
move x 150 models #4 coordinateSystem #2
move x 200 models #5 coordinateSystem #2
move x 250 models #6 coordinateSystem #2

# ---------- 3. Colour the 5 predicted structures by secondary structure ----------
cartoon preds
color preds & coil gold target c
color preds & strand lightblue target c
color preds & helix darkred target c

# ---------- 4. Keep the reference painted by pLDDT ----------
cartoon ref
color bfactor ref palette alphafold range 0,100 target c

# ---------- 5. Frame everything once and take the picture ----------
save aligned_models.png width 3000 height 3000 supersample 3 transparentBackground true
